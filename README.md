# Weihaidibalihai — bilingual website

A responsive static English/Chinese hostel website.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## Before publishing
Replace the demo:
- hostel name
- exact address / map pin
- email / phone / WeChat
- room photos
- prices
- actual room facilities and policies

The booking form currently opens an email draft. Connect it to your real booking engine, email provider, or form backend before launch.

## Content note
The itinerary uses current Weihai municipal tourism/map information for destinations such as Liu Gong Island, Torch 8th Street, International Bathing Beach, Half Moon Bay and coastal attractions. Recheck transport, opening hours and ticket requirements before publishing.
